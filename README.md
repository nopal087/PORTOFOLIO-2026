A high-impact, highly functional personal portfolio built with a **Neobrutalism** design philosophy. This web application acts as my digital resume, showcasing my professional experience, skills, and featured enterprise-level projects.

## ✨ Features
- **Neobrutalist Aesthetic**: Bold colors, heavy black borders, sharp shadows, and intentionally visible grid structures.
- **Fully Responsive**: Mobile-first approach ensuring perfect layout scaling across all devices.
- **Performance Optimized**: Built on Next.js App Router and Turbopack for lightning-fast loading and SEO capabilities.
- **Enterprise Showcase**: Dedicated sections detailing large-scale systems (WMS KAI, IRIS, Loko Kafe Management).

## 🚀 Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: TypeScript

## 📂 Featured Projects
1. **WMS KAI Services** (Next.js, Golang, PostgreSQL) - Enterprise Warehouse Management System.
2. **Loko Cafe System Management** (Next.js, Supabase) - Integrated operational management platform.
3. **IRIS System** (Next.js, Firebase) - Industrial Relations Information System.

## 💻 Getting Started

Clone the repository and install dependencies to run the portfolio locally:

```bash
git clone https://github.com/nopal087/PORTOFOLIO-2026.git
cd PORTOFOLIO-2026
npm install
npm run dev
```

Navigate to `http://localhost:3000` to see the brutalist magic in action.
